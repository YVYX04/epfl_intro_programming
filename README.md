**Yvan Richard | Fall 2026 | EPFL**

# Overview

This repository tracks the course *Introduction to Programming* taught at EPFL in Computer Science during Fall 2026.
The repository is articulated around two main directories: `mooc_i/` and `mooc_ii`. The directories contain code and notes
associated with each MOOC. Since the course is dispensed in French, the reader will see that some comments are written in French. Finally, the directory `problem_sets` contain the weekly problem sets due each week at EPFL, as well as my own solutions.
